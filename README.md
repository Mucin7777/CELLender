# Cellendar

細胞培養・アッセイのスケジュール管理 Web アプリ。
継代、播種、アッセイまでの予定と進捗をひとつのカレンダーでまとめて管理できます。

## 主な機能

| 画面 | できること |
| --- | --- |
| **今日の作業** | 今日の継代・アッセイ・培地交換、期限超過、今後 7 日間の予定、培養中の播種（Day 数つき）を一覧表示 |
| **カレンダー** | 月 / 週 / リスト表示。種類別またはライン別の色分け、フィルター、ドラッグで日付変更（元に戻すつき）、ダブルクリックで追加 |
| **細胞ライン** | ライン・ロットの登録/編集/アーカイブ/削除。P 数、前回継代日、継代間隔、次回予定日（自動計算）、継代履歴 |
| **播種記録** | 継代とは別に、播種ごとに独立して管理。由来ライン、播種日、プレート、P 数、目的、状態（培養中 / アッセイ予定 / 完了 / 廃棄）。複製も可能 |
| **アッセイ** | 播種記録に紐づくアッセイ予定（期限超過・今日・明日・7日以内…でグループ化）と実施履歴・結果の記録 |
| **設定・データ** | JSON バックアップ / 復元、CSV 出力、サンプルデータ、全削除 |

### 便利な操作フロー

- **継代する** ボタン 1 つで P 数 +1、継代履歴に記録、次回予定日を継代間隔から自動設定
- 継代の直後に「播種も記録」でそのまま播種登録へ（ライン・日付・P 数が自動入力）
- 播種登録時にアッセイ予定（Day 指定）と培地交換（N 日ごと）を一括登録
- アッセイの完了状況に応じて播種記録の状態を自動更新（すべて完了 → 「完了」）
- 最新の継代記録を取り消すと、ラインの P 数と予定日も元に戻る

## データの保存

データはブラウザの `localStorage` に自動保存されます（サーバー不要、アプリを閉じても保持）。
ブラウザのデータ消去や PC の変更に備え、**設定・データ → バックアップ (JSON)** で定期的に保存してください。

## 開発

```bash
npm install
npm run dev        # 開発サーバー (http://localhost:5173)
npm test           # ユニットテスト (vitest)
npm run build      # 本番ビルド (dist/)
npm run preview    # ビルド結果のプレビュー
```

### 技術スタック

- React 18 + TypeScript + Vite
- Tailwind CSS v4
- Zustand（状態管理 + localStorage 永続化）
- date-fns（日付計算・日本語ロケール）
- lucide-react（アイコン）

### 構成

```
src/
  types.ts              データモデル（CellLine / PassageRecord / Seeding / Assay / Task）
  store/useStore.ts     データストア（全操作・永続化）
  store/useUI.ts        モーダル・トーストの状態
  store/usePrefs.ts     表示設定（カレンダー表示形式・フィルター）
  lib/events.ts         データ → カレンダーイベントへの変換
  views/                各画面
  components/           フォーム・共通 UI
```

将来的に複数人で使う場合は、`useStore` の永続化先を Supabase / Firebase などのバックエンドに差し替えることで対応できます。

### デプロイ (GitHub Pages)

`main` ブランチへの push で `.github/workflows/deploy.yml` が実行されます。
初回のみリポジトリの **Settings → Pages → Source** を「GitHub Actions」に設定してください。
